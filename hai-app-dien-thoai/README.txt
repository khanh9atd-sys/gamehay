CÀI 2 APP LÊN ĐIỆN THOẠI (PWA)

1. Tải toàn bộ thư mục này lên kho GitHub (giữ nguyên cấu trúc thư mục):
   index.html, manifest.webmanifest, sw.js, icons/   -> game Tu Tiên (ở gốc kho)
   hoc/index.html, hoc/manifest.webmanifest, hoc/sw.js, hoc/icons/ -> app Học tiếng Trung
2. Bật GitHub Pages (Settings > Pages > Branch: main / root). Đợi 1-2 phút.
3. Mở trên điện thoại:
   - Game:  https://<tên-tài-khoản>.github.io/<tên-kho>/
   - App:   https://<tên-tài-khoản>.github.io/<tên-kho>/hoc/
4. Android (Chrome): bấm nút "Cài app" hiện ở cuối trang, hoặc menu ⋮ > "Cài đặt ứng dụng".
   iPhone (Safari): nút Chia sẻ > "Thêm vào MH chính".
5. Khi cập nhật file mới: tăng số phiên bản trong sw.js (tutien-v1 -> tutien-v2, hoc-v1 -> hoc-v2).

Tiến độ được lưu trên điện thoại. File hoc-tieng-trung.html cũ ở gốc kho có thể xóa.
